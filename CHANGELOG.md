# Changelog

## 0.1 — 2026-08-21

- First public release for Meta Quest 3 and Quest 3S.
- Added complete Android resources for 20 languages, with English as the default fallback.
- Added dual-camera SBS photo and video capture through the GPU Surface pipeline.
- Added H.264/H.265, resolution, frame-rate, bitrate, microphone, preview, guide, calibration, and display-dimming controls.
- Added recording telemetry for battery, storage, remaining time, actual FPS, dropped frames, stereo synchronization, and roll.
